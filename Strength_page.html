미니게임 짤 스튜디오

Personal Journey · 강점

나는 칼 같은 사람입니다.

칼은 갈고닦을수록 날카로워지고, 사용하는 목적에 따라 그 쓰임이 달라집니다. 복잡한 상황에서도 구조를 정리하고 실용적인 해결책을 찾아내는 능력이 저의 강점입니다.

“

경험은 칼을 갈아주는 숫돌과 같습니다. 아직 완성된 칼은 아니지만, 새로운 경험을 쌓고 부족한 부분을 연마할수록 더 날카롭고 정확한 사람이 되어갈 것입니다.

SITUATION — 상황

처음엔 막막했지만

웹 개발을 처음 접했을 때는 HTML, CSS, JavaScript와 같은 기술들이 각각 어떤 역할을 하는지조차 명확하게 알지 못했습니다. 처음에는 코드를 따라 작성하는 것만으로도 결과물이 만들어졌지만, 조금만 원하는 형태에서 벗어나면 어디서 문제가 발생했는지 찾기 어려웠습니다.

특히 직접 포트폴리오 웹사이트를 만들면서 제가 생각한 디자인과 실제 화면의 차이를 해결하는 과정에서 부족한 부분을 많이 느꼈습니다.

ACTION — 행동

이해하는 데 집중했습니다

그래서 단순히 코드를 복사해서 사용하는 것보다 왜 이렇게 작성해야 하는지 이해하는 것에 집중했습니다.

문제가 발생하면 바로 다른 코드를 가져오기보다 현재 작성한 코드가 어떤 방식으로 동작하는지 확인하고, 하나씩 수정하면서 결과를 비교했습니다. 또한 새롭게 배운 HTML, CSS, JavaScript를 직접 포트폴리오에 적용해보면서 배운 내용을 실제 결과물로 연결하려고 했습니다.

이해하기 어려운 개념은 작은 예제를 만들어 직접 실행해보고, 같은 기능을 여러 가지 방법으로 구현해보며 차이를 비교했습니다.

RESULT — 결과

점점 더 성장하고 있습니다

그 과정을 반복하면서 처음에는 단순히 코드를 따라 작성하는 수준이었다면, 지금은 원하는 결과를 만들기 위해 어떤 기술과 방법을 사용해야 할지 스스로 고민하는 단계까지 발전하고 있습니다.

아직 많은 프로젝트나 실무 경험을 가진 사람은 아니지만, 새로운 기술을 접했을 때 두려워하기보다 직접 부딪혀보고 부족한 부분을 찾아 채워가는 방법을 배웠습니다.

앞으로도 경험을 하나씩 쌓아가며 제 부족한 부분을 끊임없이 갈고닦는 사람이 되고 싶습니다.
