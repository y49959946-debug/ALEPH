제로트러스트·XDR 보안 서비스

프로젝트 개요

BYTE BACK 방어전 13~22단계에 해당하는 보안 서비스 개발 과제입니다. 접근 제어와 위협 탐지·대응을 한 서비스로 묶고, 실시간 공격 시나리오 속에서 운영하며 v1.0까지 출시했습니다.

개발 단계22 / 22보안 서비스 개발 22단계를 모두 통과했습니다.
검증13–22단계제출한 소스 코드를 AI 판정 시스템으로 검증받았습니다.
출시v1.0회귀 테스트를 거쳐 출시했습니다.

맡은 일

개인 프로젝트입니다. 13~20단계에서는 과정이 제공한 시작 틀(서버·화면·연결 코드) 위에, 사용자·세션, 접근 판정, 접속 기록·XDR 경보, 상태·오류, AI 연결 점검, AI 사건 설명, 조치 상태, 취약점 조회 결과를 보여 주는 표시 함수 8개를 작성했습니다.

21~22단계에서는 실행 설명서·구성도와 새 환경 재현 기록을 작성했고, 과정이 끝난 뒤 관제 대시보드와 설치 프로그램은 새 저장소에서 직접 확장했습니다. 코드는 AI 코딩 도구의 도움을 받아 작성했습니다.

만든 기능

사고 대응
승인 기반 사고 대응, 보안 정책 버전 관리·롤백, 백업과 선택 복구 기능을 개발해 사고 뒤 원래 상태로 되돌릴 수 있게 했습니다.
운영
실시간 공격 시나리오에서 정책 변경 요구를 처리했고, 방어에 실패한 요청마다 Postmortem을 남긴 뒤 회귀 테스트를 거쳐 v1.0을 출시했습니다.
배포
설치 문서·시스템 구성도를 포함한 배포 패키지로 제품화했습니다.

배운 점

보안 화면에서 가장 위험한 것은 “확인하지 못한 것”을 “문제없음”처럼 보여 주는 것이라는 점을 배웠습니다. 그래서 모든 값에 출처를 붙이고, 확인하지 못한 기능은 설명서에도 미확인으로 남겼습니다.

다음에는 실제 연결 환경을 먼저 확보해, 화면이 아니라 실제 경보와 조치 결과로 동작을 검증하겠습니다.

이어진 작업: Veil 0.1.0 배포

과정이 끝난 뒤 관제 대시보드를 새 저장소에서 확장해, PC에서 쓰는 관제 앱 Veil로 만들었습니다. 상단 상태 카드 4개와 추이·기록을 한 화면에서 보며, 설치 프로그램 0.1.0을 GitHub 릴리스로 배포했습니다.
